# perfume-recommender
## How to Run

Clone the repository and navigate into its folder:

```bash
git clone https://github.com/ja9kyl3/perfume-recommender.git
cd perfume-recommender
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Start the Streamlit application:

```bash
streamlit run app.py
```

Then open the local URL provided in your terminal, usually `http://localhost:8501`.
